# 🎮 Esports Platform — Паспорт проекта

> **Последнее обновление:** Сентябрь 2026  
> **Статус:** первая production-архитектура подготовлена

## Описание

Киберспортивная платформа для проведения турниров по Dota 2, CS2 и другим дисциплинам.

Пользователи могут регистрироваться, входить в аккаунт, просматривать турниры и команды, а авторизованные пользователи — подавать заявку команды на участие в турнире.

## Технологический стек

- HTML5 + CSS3 + Vanilla JavaScript
- Supabase Auth
- Supabase PostgreSQL + Row Level Security
- GitHub — исходный код и история изменений
- Vercel — production/preview hosting

## Данные

- Dota 2 Ingogames 2026 Season 1 импортирован в Supabase как завершённый турнир.
- `data/tournament-dota2-2026.json` сохранён как исторический fallback для части детальных данных/сеток.
- `data/tournament-cs2-2026.json` — намеренно пустая валидная JSON-заготовка для будущего турнира. Точные параметры CS2 не должны выдумываться и будут добавлены после утверждения названия, дат, формата и лимита команд.

## Безопасность

Публичный frontend использует только Supabase publishable key. Service-role/secret keys в браузер и репозиторий не добавляются. Для пользовательских таблиц включён RLS.

## Локальный запуск

Проект можно открыть через любой локальный HTTP server. Для полноценной Auth-проверки рекомендуется тестировать deployment на Vercel, поскольку redirect URL подтверждения email должен совпадать с разрешённым URL в Supabase Auth.
